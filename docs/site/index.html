Hidden Element

A reinforcement-learning environment where an agent rediscovers an unknown radioactive element the way it was historically done: dissolve the ore, separate it chemically, measure every product, and follow the signal until the new element is pure. Each seed generates fresh chemistry, so memorised facts do not help.

History →Every environment version, its settings, every recorded run against the reference script, and where each model went wrong. Replay →Animated step-by-step replay of any recorded run, with the raw tool call and response at every step.

One episode

  1. Wait out the interferer. The ore holds a short-lived radioactive element (half-life 8–20 h) that would mislead the activity readings. Waiting lets it decay.
  2. Precipitate and follow the activity. Five reagents each split a solution into a precipitate and a filtrate. Keep whichever product holds the target's activity.
  3. Identify the carrier. The target behaves like one known element in every reagent; reagents cannot separate the two.
  4. Fractional crystallisation. The target is enriched in crystals relative to its carrier. Each round trades recovery for purity; recycling the mother liquor recovers lost target.
  5. Report and submit. Measure the sample's apparent atomic weight, correct it for the contaminants seen in the spectrum, and submit the sample with the carrier's symbol.

Tools

Every call except rules and list_samples costs one action from a budget of 100. Measurements are noisy; time only moves when a tool is called.

dissolve

Solid to solution. Loses 1% of every element.

precipitate

Add a reagent and filter: precipitate + filtrate. 3 units per reagent.

crystallize

Crystals hold a chosen fraction (0.05–0.95) of the mass; the rest stays in the mother liquor.

combine

Merge samples, e.g. recycled crystals back into the main batch.

wait

Let time pass; radioactive elements decay.

measure_activity

Geiger counts with Poisson noise and a 30 cpm background.

weigh

Mass in grams, with noise.

spectrum

Emission lines above each element's detection limit; a new line means a new element.

atomic_weight

Mass-weighted mean atomic weight of everything in the sample.

submit

Ends the episode: sample, target's atomic weight, carrier symbol.

Scoring

Computed by the lab server from the hidden state, never from anything the agent writes.

purity     = target mass / sample mass
recovery   = target in sample / target in ore
separation = min(1, purity / 0.9) × min(1, recovery / goal)
report     = (½ weight credit + ½ carrier credit) × min(1, recovery / goal),   only if purity ≥ 0.5
reward     = 0.7 × separation + 0.3 × report        (0 if nothing is submitted)

The recovery goal is 0.30 in the current version (0.15 before). Doing nothing, submitting the raw ore, or stopping after one separation all score about 0.
