How human is the way LLMs reason through a scientific discovery?

Claude, GPT and Gemini models each try to isolate an unknown radioactive element in a simulated lab, the way Marie Curie did: separate the ore, follow the radioactivity, purify by fractional crystallisation. Every tool call carries the model's own one-sentence key reason. We score how well each model does and how closely its decisions, order of work and stated reasons resemble a human expert's.

Method

Task

Each seed generates new hidden chemistry, so memorised facts do not help. The model sees only the rules and its tool results; reward (0–1) is computed from the true content of the submitted sample: purity, recovery, the target's atomic weight and its chemical carrier.

Reasons

Every tool has a required reason argument: one sentence giving the key reason for the decision. It is recorded with the call and shown step by step on the decisions page, side by side with a human.

Human references

The human expert protocol is a fixed procedure modelled on the Curies' method, with a human expert's reason for every step. People can add their own runs by playing in the terminal (python -m llm_bench.human play); they then count as human references too.

Human-likeness

Decisions: agreement on the key decisions above. Sequence: 1 − normalised edit distance between phase sequences. Tool mix: 1 − Jensen–Shannon distance of tool usage. Concepts: cosine similarity of the concepts the reasons invoke.
